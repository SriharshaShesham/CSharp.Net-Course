# C# .NET Course for Beginners

Code from a beginner C# course: every example from class, plus practice tasks and their solutions.

## Contents

| Folder | Topics |
|---|---|
| `1. Basics` | Console input and output, scopes and naming conventions, conditions, switch, loops, functions, classes, properties, constructors |
| `2. DataStructrues` | Arrays, lists, stacks, queues |
| `3.ProblemSolving` | Practice tasks: student records, bank management with classes, collections, combinations |
| `4.Html` | HTML basics, styling, Bootstrap |
| `AdditionalConcepts` | Extra notes, e.g. measuring performance |

## Running an example

Each example is a small console project. Open its folder in Visual Studio or VS Code, or run:

```bash
dotnet run
```

The companion [Java course](https://github.com/SriharshaShesham/JavaCourse) covers the same material in Java.
